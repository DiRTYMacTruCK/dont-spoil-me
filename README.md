# 🙈 dont-spoil-me — Jellyfin Plugin

Replaces episode thumbnail images with the series poster so spoiler screenshots never ruin your next watch.

- Unwatched episodes show the series poster instead of the episode thumbnail
- When an episode is marked watched, the real thumbnail is fetched back automatically
- Mark it unwatched again and it goes back to the series poster
- Works on any Jellyfin client (web, mobile, TV apps)

---

| Jellyfin version | Plugin version |
|------------------|----------------|
| 12.x             | 1.1.6          |
| 10.11.x          | 1.1.3          |

The catalog serves the right version for your server automatically.

## How It Works

The plugin applies one rule to every episode:

- Nobody on the server has played it: the episode image is replaced with the series poster
- Anyone on the server has played it: the real thumbnail is restored with a metadata refresh

The rule runs whenever an episode is added, updated, or marked watched/unwatched. It also runs across the whole library about 60 seconds after Jellyfin starts. Because it checks the actual image files rather than remembering what it did, restarts, missed events, and toggling watched back and forth all fix themselves.

Watched state is per user in Jellyfin, but the episode image is shared. If any user has played an episode, its real thumbnail is shown to everyone.

Images stored next to your video files (in the media folder) are never touched. Only images in Jellyfin's metadata folder are swapped.

## Install via Jellyfin (Recommended)

1. Open Jellyfin Dashboard
2. Go to Plugins, then Repositories
3. Click New Repository and add:
     Name: dont-spoil-me
     URL:  https://dirtymactruck.github.io/dont-spoil-me/manifest.json
4. Click Save
5. Go to Plugins and click the Available tab
6. Find dont-spoil-me and click Install
7. Restart Jellyfin — this is required for the plugin to activate

The startup sweep handles your existing library, so no manual metadata refresh is needed.

## Install Manually

1. Download the zip for your Jellyfin version from the releases page:
   https://github.com/DiRTYMacTruCK/dont-spoil-me/releases

   Jellyfin 12.x:    dont-spoil-me_1.1.6.0.zip
   Jellyfin 10.11.x: dont-spoil-me_1.1.3.0.zip

2. Unzip it to get Jellyfin.Plugin.DontSpoilMe.dll

3. Copy the DLL into your Jellyfin plugins folder:

Docker:
  mkdir -p ~/docker/jellyfin/config/plugins/DontSpoilMe
  cp Jellyfin.Plugin.DontSpoilMe.dll ~/docker/jellyfin/config/plugins/DontSpoilMe/
  docker restart jellyfin

Bare metal Linux:
  sudo mkdir -p /var/lib/jellyfin/plugins/DontSpoilMe
  sudo cp Jellyfin.Plugin.DontSpoilMe.dll /var/lib/jellyfin/plugins/DontSpoilMe/
  sudo chown -R jellyfin:jellyfin /var/lib/jellyfin/plugins/DontSpoilMe
  sudo systemctl restart jellyfin

Windows:
  Copy Jellyfin.Plugin.DontSpoilMe.dll to:
  C:\ProgramData\Jellyfin\Server\plugins\DontSpoilMe\
  Then restart the Jellyfin service.

## Build from Source

Only needed if you want to compile the plugin yourself, for example after a Jellyfin update.

Requirements: Docker or bare metal Jellyfin, internet access

  git clone https://github.com/DiRTYMacTruCK/dont-spoil-me.git
  cd dont-spoil-me
  bash build.sh

The script handles everything automatically:
- Copies Jellyfin DLLs from your running instance
- Detects the .NET version your Jellyfin needs and installs it if missing
- Builds the plugin
- Installs and restarts Jellyfin

All plugin source code is generated by build.sh.

## Settings

There's no working settings page (see Known Issues), so edit the config file directly and restart Jellyfin.

Docker:
  nano ~/docker/jellyfin/config/plugins/configurations/Jellyfin.Plugin.DontSpoilMe.xml

Bare metal Linux:
  sudo nano /var/lib/jellyfin/plugins/configurations/Jellyfin.Plugin.DontSpoilMe.xml

  <?xml version="1.0" encoding="utf-8"?>
  <PluginConfiguration>
    <IsEnabled>true</IsEnabled>
    <OnlyUnwatched>true</OnlyUnwatched>
  </PluginConfiguration>

IsEnabled (default true)
  Master on/off switch

OnlyUnwatched (default true)
  true:  watched episodes show their real thumbnail, unwatched show the series poster
  false: every episode shows the series poster, watched or not

## Troubleshooting

Check what the plugin is doing:
  Docker:     docker logs jellyfin 2>&1 | grep -i "dont-spoil"
  Bare metal: journalctl -u jellyfin | grep -i "dont-spoil"

  On startup you should see:
    dont-spoil-me: started (startup sweep in 60s)
    dont-spoil-me: startup sweep done — N episodes checked, X hidden, Y restored

Watched episode still showing the series poster:
  The real thumbnail is re-downloaded by a metadata refresh, which can take a few seconds.
  Hard-refresh the page or clear the client's image cache. If it still doesn't come back,
  restart Jellyfin and the startup sweep will retry it.

Plugin not showing in dashboard:
  Check the DLL is in the correct folder and Jellyfin was restarted.

Developer and Repository show Unknown:
  Uninstall the plugin and reinstall it via the repository method above.
